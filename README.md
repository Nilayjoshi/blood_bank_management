# Blood Bank Management System
  - The Blood Bank Management System is designed to manage and streamline the operations of a blood bank. This system facilitates the management of blood donations, donor information, blood inventory, and the distribution of blood to recipients. It ensures efficient record-keeping, easy retrieval of information, and seamless operations to save lives by providing timely access to blood.
> Features:
  - User Authentication and Authorization.
  - Searching Functionality.
  - Donate and Request Blood.
  - Manage Request and Inventory as a Hospital User.
> Technologies:
  - Frontend
    - HTML
    - CSS
    - Bootstrap
  - Backend
    - Python
    - Django
  - Database
    - SQLite
